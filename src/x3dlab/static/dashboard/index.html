      What this page sends to Chrome DevTools

      • Performance: record a trace. Server work (validator, MCP calls, model calls) appears as custom tracks in the x3d.lab group next to X_ITE's frames. Turn on Capture settings › Show custom tracks if you do not see them.
      • Console: one collapsed group per finished scene with a table of issues; styled lines per event (level follows the selector on this page). Type x3dlab.help().
      • Network: events is the live stream (EventStream tab). Every API call has a Server-Timing header (Timing tab): gateway, validator and MCP time.
      • Custom formatters: enable Settings › Console › Custom formatters and validator issues print as compact badges.
      • Copilot tab: window.__x3dcopilot exposes its viewer, editor and validator.
